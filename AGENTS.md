# Branch Naming & Workflow

Before starting any work on a feature or bug fix:

1. **Create a branch** using the following naming conventions:
   - New features: `feature/<issue-name>` (e.g. `feature/game-time-tracking`)
   - Bug fixes: `bug/<issue-name>` (e.g. `bug/fix-session-timer`)
   - Use kebab-case, keep it short and descriptive.
2. **Switch to that branch** before making any changes.
3. Never commit directly to `main` or the default branch.
